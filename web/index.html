How it works

The image is processed by three pipelines. Hybrid (the main one): a fine-tuned YOLO11n detector finds each car. If it finds none, a classical edge and contour region proposal takes over. Each crop gets 8% padding and, if it is dark, CLAHE contrast enhancement. A ConvNeXt-Tiny fine-tuned on Stanford Cars then predicts the class, and predictions below the confidence threshold are shown as Uncertain with the top-5 candidates. Deep learning only classifies the whole image without detection. Classical runs CLAHE, Canny edges, contours and gradient features in the browser; its HOG + LBP + colour + geometric SVM was evaluated offline.

Limitations

Only the 196 Stanford Cars classes are known, mostly US-market cars up to 2012. Any other car is mapped to the closest known class, which is why low-confidence predictions are flagged. Model years with near-identical styling, very low resolution and heavy blur are the hardest cases. No number-plate recognition or tracking is performed.

Privacy

Your image never leaves your device. All models run locally in the browser through ONNX Runtime Web and OpenCV.js.
