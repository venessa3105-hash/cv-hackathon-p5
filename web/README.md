# Fine-Grained Vehicle Recognition (CV Hackathon 2026, P5)

A browser app that detects cars (YOLO11n) and predicts make, model and year
(ConvNeXt-Tiny, 196 Stanford Cars classes). It runs entirely client-side with
ONNX Runtime Web and OpenCV.js. Models load from `vene-05/p5-convnext-cars`.
